# Brand Assets Directory

This folder holds brand identity assets required by the UI application.

## Expected Files
- `logo-full-light.png` — Horizontal full logo for light theme (expanded sidebar/navbar)
- `logo-full-dark.png` — Horizontal full logo for dark theme
- `logo-short-light.png` — Square icon logo for light theme (collapsed sidebar)
- `logo-short-dark.png` — Square icon logo for dark theme
- `favicon-light.ico` — Favicon for light theme
- `favicon-dark.ico` — Favicon for dark theme

Refer to `../reference/brand-identity.md` for sizing rules and clearance margins.
